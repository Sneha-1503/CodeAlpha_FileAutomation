# CodeAlpha_FileAutomation

# 📁 File Automation using Python

## 📌 Project Description
This project automates the process of organizing files by moving all `.jpg` images from one folder to another using Python.

---

## 🚀 Features
- Automatically scans folder for `.jpg` files
- Moves files to a separate directory
- Creates destination folder if not present
- Counts total files moved

---

## 🧠 Concepts Used
- os module (file handling)
- shutil module (file operations)
- loops (for iteration)
- conditional statements

---

## 💻 How It Works
1. Program scans the source folder
2. Checks each file extension
3. If file is `.jpg`, it moves it to destination folder
4. Prints status of each moved file
